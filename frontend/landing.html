01 · The answer loop

Automation first. The model only sees what needs judgment.

Every question passes through the same four stages. Exact fields and document checks never touch a model. Everything else recalls evidence from memory and is drafted under guardrails that have the last word.

01

Exact fields

GSTIN, PAN, entity type, address. Looked up directly from the company record, with no model call and full confidence.

02

Document check

Every requested document is checked against the inventory. On file, it's attached. Not held, it's flagged as a gap.

03

Recall and draft

Judgment questions recall evidence from Hindsight. The model must cite evidence ids, or declare that nothing answers it.

04

Guardrails

Uncited or low-confidence drafts go to a human. Claims about certificates the company doesn't hold are blocked.

02 · Recall, not search

One question lights up only the memories that answer it.

Each bar is a memory: a fact, a document, a past answer, a reviewer's correction. Recall pulls a contiguous run of relevant evidence, and the draft is built from that run alone. What isn't recalled can't be claimed.

04 · Questions
What does Hindsight actually do here?

It is the only place company knowledge lives. Facts, documents and every past answer are retained into one memory bank per company, with dates. Each question recalls evidence from it, a reflect call writes the brief before answering, and every reviewer edit is retained back, so the next questionnaire starts smarter.

What stops it from making things up?

Three layers. Exact fields and documents are answered without a model. The model must call a tool with the evidence ids it used, or declare a gap. Then deterministic guardrails check the draft: uncited or low-confidence answers go to review, and positive claims about certificates not on file are blocked.

How does it get better over time?

Every approval and edit is retained as a memory with the reviewer's reason. When a similar question appears on the next client's questionnaire, recall returns the corrected answer first and the draft cites it.

What happens when a fact changes?

Facts are retained with the date they became true. Turnover is one memory per financial year, so a new year's figure appears at the top of a timeline instead of overwriting the old one.

The last questionnaire is the first draft of the next one.
